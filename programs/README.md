# 오른손 제스처 수집 안내

이번 명령 제스처는 `swipe_left`, `make_fist`, `finger_snap` 세 가지입니다. 오른손으로 수행하며 NPZ 파일 하나에는 동작 한 번만 담습니다. 명령하지 않는 상태는 보조 데이터인 `no_gesture`로 구분합니다.

수집기는 `finger_snap` 같은 새 라벨도 입력받아 저장합니다. 이름에는 영문·숫자·하이픈·밑줄만 사용하세요. 단, 새 라벨을 수집한다고 기존 모델이 자동으로 지원하지는 않습니다. 현재 전처리·학습·서비스는 `swipe_left=0`, `make_fist=1`, `no_gesture=2`, `finger_snap=3`의 네 클래스를 지원합니다. 오른손 검사와 녹화 품질 기준은 새 라벨에도 동일하게 적용됩니다.

## 참가자 ID와 실행

팀원 6명은 배정받은 `p001`~`p006` 중 자신의 ID를 계속 사용합니다. 같은 사람은 라벨이나 촬영 날짜가 바뀌어도 같은 ID를 사용합니다.

환경 설정이 끝난 프로젝트 루트에서 실행합니다.

```powershell
.\.venv\Scripts\python.exe .\programs\collect_gesture.py
```

자신의 ID와 이번에 수집할 라벨을 입력합니다.

```text
Participant ID: p001
Gesture Label: swipe_left
```

라벨은 안내된 소문자 표기 그대로 입력합니다. 다른 라벨로 바꾸려면 `Q`로 종료한 뒤 다시 실행합니다.

| 키 | 조작 |
| --- | --- |
| `Space` | 녹화 시작 / 다시 누르면 종료 후 저장 |
| `R` | 실수한 녹화를 취소하고 준비 상태로 돌아가기 |
| `Q` | 종료. 녹화 중인 샘플은 저장하지 않음 |

카메라 창을 선택한 상태에서 키를 누릅니다. 가능하면 반대 손으로 키보드를 조작하고 오른손은 동작 종료 자세를 유지합니다.

## 공통 촬영 규칙

- 오른손 전체가 화면 안에 보이게 하고 다른 손은 화면 밖에 둡니다.
- 동작 전후의 짧은 정지도 함께 녹화합니다. 매번 정확히 같은 길이로 맞출 필요는 없습니다.
- 준비와 마무리를 포함해 한 녹화는 약 1~2초를 목표로 합니다. 저장 허용 범위는 0.6~2.5초이며 최소 20프레임이 필요합니다.
- 한 녹화 안에서 동작을 여러 번 반복하지 않습니다. 저장 후 다음 동작을 준비합니다.
- 속도, 시작 위치, 카메라 거리, 배경을 조금씩 바꿉니다. 손이 검출되지 않을 정도로 어둡거나 화면 밖으로 벗어나는 환경은 피합니다.
- 먼저 각 명령을 사람당 10개씩 시험 수집해 확인합니다. 이후 본 수집에서는 두 명령의 저장 개수를 비슷하게 맞춥니다.

## swipe_left

**오른손을 편 상태에서 수행자 자신의 왼쪽으로 한 번 이동합니다.** 화면을 보며 방향을 반대로 바꾸지 마세요. 현재 영상은 좌우 반전하지 않으므로 화면에서는 오른쪽으로 이동해 보일 수 있습니다.

1. 오른손을 펴고 손바닥이 카메라를 향하도록 준비합니다. 왼쪽으로 이동할 공간을 남깁니다.
2. `Space`로 녹화를 시작하고 잠깐 준비 자세를 유지합니다.
3. 편 손을 자신의 왼쪽으로 한 번 움직입니다. 이동하면서 주먹을 쥐지 않습니다.
4. 도착한 위치에서 잠깐 멈추고 `Space`로 저장합니다.
5. **저장 후에** 손을 시작 위치로 되돌립니다. 복귀 동작은 해당 파일에 넣지 않습니다.

짧은 이동·보통 이동·큰 이동을 모두 포함합니다. 의도적으로 수행한 짧은 스와이프도 `swipe_left`입니다.

## make_fist

**오른손 손바닥을 쫙 편 상태에서 손가락을 접어 주먹을 한 번 쥡니다.** 처음부터 주먹인 정지 자세가 아니라 편 손에서 주먹으로 변하는 과정을 담습니다.

1. 오른손 손바닥이 카메라를 향하도록 하고 손가락을 충분히 폅니다.
2. `Space`로 녹화를 시작하고 편 손을 잠깐 유지합니다.
3. 손목 위치는 가능한 한 유지하면서 손가락을 접어 주먹을 쥡니다.
4. 주먹을 잠깐 유지한 채 `Space`로 저장합니다.
5. **저장 후에** 손을 다시 폅니다. 주먹에서 편 손으로 돌아오는 동작은 해당 파일에 넣지 않습니다.

손가락을 접는 속도와 시작 위치에 자연스러운 변화를 줍니다. 손을 크게 이동하는 동작과 섞지 않습니다.

**손목 이동량 경고가 표시되어도 정상일 수 있습니다.** 현재 경고는 손목의 시작·종료 거리만 확인합니다. `make_fist`는 손목이 거의 움직이지 않아도 올바른 동작이며, 경고 때문에 일부러 손목을 움직일 필요는 없습니다. 손가락을 포함한 21개 랜드마크는 모두 저장됩니다.

## no_gesture 보조 데이터

`no_gesture`는 세 번째 실행 명령이 아니라 **아무 기능도 실행하면 안 되는 상태**를 학습하기 위한 라벨입니다. 이번 두 명령 데이터와 별도로 짧게 수집합니다.

1. 프로그램을 다시 실행하고 라벨에 `no_gesture`를 입력합니다.
2. 오른손이 보이는 상태에서 `Space`로 녹화를 시작합니다.
3. 약 1~2초 동안 아래 예시 중 한 가지 상태를 유지합니다.
4. `Space`로 저장합니다. 우선 사람당 10개 정도를 여러 예시로 나누어 수집합니다.

- 편 손을 가만히 유지하기
- 녹화 시작 전부터 쥔 주먹을 가만히 유지하기
- 손목을 유지한 채 손가락 일부만 조금 움직이기. 주먹을 완성하는 동작은 제외
- 정지 상태에서 생기는 자연스러운 작은 손떨림

손을 편 상태에서 주먹으로 쥐는 과정은 `make_fist`, 의도적인 작은 왼쪽 이동은 `swipe_left`로 저장합니다. 이를 `no_gesture`로 중복 수집하지 않습니다. 손목 이동량 경고는 정지 샘플에서 예상되는 안내이며 저장을 막지 않습니다.

손이 아예 없는 영상은 현재 수집기가 저장을 거부하므로 이번에는 수집하지 않습니다.

## 저장 확인과 전달

터미널에 `Saved:`와 파일 경로가 표시되는지 확인합니다. 품질 검사 실패로 `Discarded`가 표시되면 저장되지 않았으므로 다시 녹화합니다. 손 검출률은 80% 이상이어야 하고 연속 미검출은 최대 5프레임까지 허용됩니다.

자신의 ID로 시작하는 파일만 모아 라벨별 폴더를 유지한 채 전달합니다.

```text
dataset/swipe_left/p001_swipe_left_0001.npz
dataset/make_fist/p001_make_fist_0001.npz
dataset/no_gesture/p001_no_gesture_0001.npz
```

## 긴 연속 영상은 추후 별도 수집

긴 연속 영상은 `정지 → 명령 동작 → 원위치 복귀 → 정지 → 다음 명령 동작`을 끊지 않고 담는 자료입니다. 실제 서비스에서 명령을 한 번만 실행하는지, 복귀나 정지 중에는 실행하지 않는지 확인하는 데 사용합니다.

**이번 수집에서는 긴 연속 영상을 녹화하지 않습니다.** 현재 프로그램은 최대 2.5초의 단일 샘플 수집용입니다. 자동 구간 감지 기능을 만들 때 별도 녹화 방법과 명령 구간 표시 방법을 안내한 뒤 수집합니다.

## finger_snap 수집

오른손으로 손가락을 한 번 튕기는 동작을 한 NPZ에 담습니다. 참가자 ID는 동일하게 유지하고 라벨은 `finger_snap`으로 입력하세요. 소리를 녹음하거나 소리로 분류하는 것이 아니라 손 랜드마크의 시간 변화를 사용합니다. 기존 품질·시간 기준은 그대로 적용됩니다.
