## 읽는 법 / 발표 멘트

- **스와이프는 누구에게나 100%.** 주먹도 82~100.
- **약점 두 곳은 사람 스타일 차이**: p003 은 스냅할 때 손가락을 더 접어 주먹으로 보이고, p004 의 no_gesture 는 "움직이는 주먹 모양"이라 스냅으로 보인다. 그 사람이 학습에 들어가면 사라지는 문제이고, 시연 모델에는 6명이 다 들어 있다(1번 표).
- **룰 기반이 처음 보는 사람에서 평균적으로 더 높다(93.0 vs 89.0). 숨기지 않는다.** 3클래스 때도 같았다(97.3 vs 95.1).
  반박 근거: ① 룰 임계값은 이 데이터를 보고 사람이 맞춘 값이다. ② p004 처럼 예상 밖 동작에서 룰이 무너진다(no_gesture 71). ③ 제스처가 늘수록 룰은 짜기 어렵다(스냅 룰은 6명 데이터를 보고 세 번 고쳤다). ④ 실시간 오작동 0 은 모델 + 구간 감지 규칙 + 상식검사 + 쿨다운의 조합이다(`docs/team_conventions.md` 3-1 실측 기록).
- **no_gesture 재현율이 가장 흔들린다(40~79, 표준편차 최대 34).** 사람마다 "아무것도 아닌 동작"의 종류가 달라서다. 되감기·내리기 합성으로 올린 것이 이 정도이고, 더 올리려면 각자 다양한 no_gesture 를 더 찍어야 한다.

## 팀원 LSTM 과 비교하는 법

1. 모델끼리: 2번 표와 같은 절차(사람 단위 제외, 시드 3개). `compare_models.py --archs gru lstm ...` 로 우리 LSTM(셀만 다름, 층·유닛 동일) 대조군을 뽑고, 팀원 모델 파일이 있으면 `scripts/eval_model.py --model <파일> --persons <p>` 로 같은 데이터에 채점한다. 팀원 LSTM 구조가 다르면 표에 각주.
2. 시스템끼리: 같은 웹캠 세션에서 실행률·오작동(4번 표). 규칙 층의 가치는 여기서 드러난다.
3. 팀원이 랜덤 분할로만 냈다면 1번 표(100%)와 나란히 놓되, 둘 다 학습 참여자 기준임을 밝힌다.
